## Step-by-step trace

### 1. `FileMount` struct — `pkg/container/client.go:124`

```go
type FileMount struct {
    Source      string    // host path
    Destination string    // container path
    Options     []string  // mount options (e.g. "z" for SELinux relabeling)
    Propagation string
    RW          bool
}
```

`Source` is the absolute host path; `Destination` is the in-container path. The `Options` slice maps to the trailing `:z` in a podman/docker bind mount spec.

### 3. How mounts become bind specs — `internal/nonkube/client/compat/container.go:318`

During `ContainerCreate`, each `FileMount` is translated to a podman/docker bind string:

```go
for _, mount := range newContainer.FileMounts {
    if mount.Source == "" || mount.Destination == "" {
        continue
    }
    mode := ""
    if len(mount.Options) > 0 {
        mode = ":" + strings.Join(mount.Options, "")
    }
    spec.HostConfig.Binds = append(spec.HostConfig.Binds,
        fmt.Sprintf("%s:%s%s", mount.Source, mount.Destination, mode))
}
```

For the certs mount this produces: `~/.local/share/skupper/namespaces/default/runtime/certs:/etc/skupper-router/runtime/certs:z`

## Verification

**Confirmed**: for the compat renderer, a site render produces a container with exactly two bind mounts:

1. `<siteHome>/runtime/router:/etc/skupper-router/config:z`
2. `<siteHome>/runtime/certs:/etc/skupper-router/runtime/certs:z`

The `ProxyProfiles` map in the router config is empty (as verified in Task 1), and no `runtime/proxies` mount exists.

## Key observations for proxy implementation

1. **Adding the mount is mechanical**: Append a third `FileMount` to the `FileMounts` slice in both renderers:

   Compat (`site_state_renderer.go:234`):
   ```go
   {
       Source:      path.Join(siteConfigPath, string(api.ProxyProfilesPath)),
       Destination: "/etc/skupper-router/runtime/proxies",
       Options:     []string{"z"},
   },
   ```

   Bundle (`site_state_renderer.go:116`):
   ```go
   {
       Source:      path.Join("{{.NamespacesPath}}", "{{.Namespace}}", string(api.ProxyProfilesPath)),
       Destination: "/etc/skupper-router/runtime/proxies",
       Options:     []string{"z"},
   },
   ```

2. **Path constant already exists**: `api.ProxyProfilesPath = "runtime/proxies"` is defined at `pkg/nonkube/api/environment.go:21`. No new constant needed.

3. **SELinux `z` option**: All existing mounts use `Options: []string{"z"}` for shared SELinux label relabeling. The proxy mount must do the same.

4. **Directory pre-creation**: The mount source directory must exist on the host before the container starts. Per plan-review.md suggestion 2, `api.ProxyProfilesPath` should be added to `configurationDirectories` in `fs_config_renderer.go:22` to ensure it's created during rendering, even when no proxy is configured.

5. **Order invariant**: mounts are consumed as a slice — order doesn't affect functionality. Adding the proxy mount at the end of the `FileMounts` slice is the cleanest approach.

6. **Both renderers must be updated**: compat (podman/docker live deploy) and bundle (offline tarball) use independent `prepareContainers()` implementations. Both need the same mount entry.
